# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening an issue with the `security` label.

We will respond within 72 hours and provide a timeline for remediation.

## Security Scan

This repository uses gitleaks for secret scanning. Do not disable or circumvent the security workflow.
